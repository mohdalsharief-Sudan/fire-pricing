# نظام تسعير أنظمة مكافحة وإنذار الحريق (Fire Pricing) 🔥

تطبيق سطح مكتب احترافي لمهندسي ومقاولي أنظمة الحماية من الحريق: إدارة عروض الأسعار، حساب التكاليف وهوامش الربح، والتحكم الشامل بمكتبة الأجهزة والمواد.

---

## 🚀 الميزات الأساسية

- **تسعير تفصيلي:** توريد + تركيب + عمالة + مواد + خدمات + نفقات عامة + طوارئ + ربح + ضريبة + خصم
- **مكتبة متكاملة:** أكثر من 300 صنف (كواشف، لوحات، مضخات، طفايات، مواسير...) مع تعديل شامل للأسعار
- **إدارة المشاريع:** حفظ، استرجاع، بحث، حذف، وترقيم عروض تلقائي
- **سجل أسعار:** تتبع كل تغيير سعر بتاريخه وسببه + تحديث أسعار شامل
- **سجل عملاء:** مع اختيار العميل وربطه بالمشروع
- **إعدادات الشركة:** اسم الشركة، الشعار، الشروط — تظهر في عرض السعر
- **عرض سعر بوضعين:** 📄 عرض العميل (بدون تكاليف) / 📊 التقرير الداخلي (بالأرباح)
- **استيراد أسعار من Excel / CSV** مع مطابقة ذكية للأسماء
- **طباعة / PDF / تصدير Excel / نسخ ملخص**

## 🔗 الربط مع FireEngineerAI (نظام إدارة المشاريع)

هذا البرنامج **متكامل مع برنامج [FireEngineerAI](https://github.com/mohdalsharief-Sudan/Fire-Engineer-AI)** — يكملان دورة العمل:

```
Fire Pricing (عرض السعر)  →  FireEngineerAI (تنفيذ المشروع + فواتير + صيانة)
```

### 📤 1) تصدير العملاء
- تبويب **"العملاء"** ← زر **"📤 تصدير العملاء (لبرنامج الإدارة)"**
- يحفظ ملف `clients-export.json` — يُستورد في FireEngineerAI

### 📤 2) تحويل العرض المعتمد إلى عقد
- تبويب **"عرض السعر النهائي"** ← زر **"📤 تحويل العرض المعتمد إلى عقد"**
- ينشئ ملف JSON يتضمن:
  - **العميل** (كل بياناته + السجل التجاري)
  - **المشروع** (الاسم، الموقع، المساحة)
  - **العقد** بالقيمة **الفعلية بعد الخصم** (وليس قيمة العرض قبل الخصم)
  - **البنود** بأسماءها وكمياتها وأسعار بيعها

> ⚠️ **مهم:** لا تصدّر إلا العرض **المعتمد من العميل** — فالعرض غير المعتمد لا يصبح مشروعاً.

### ثم في FireEngineerAI:
- **"📥 استيراد من التسعير"** (صفحة العملاء) ← لاستيراد العملاء
- **"📥 استيراد عرض معتمد"** (صفحة المشاريع) ← ينشئ العميل + المشروع + العقد تلقائياً
