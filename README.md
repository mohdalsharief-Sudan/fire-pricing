# نظام التسعير الذكي لأنظمة الإطفاء والإنذار من الحريق

برنامج احترافي لتسعير مشاريع توريد وتركيب أنظمة الحماية من الحرائق، بواجهة عربية كاملة.

## المزايا

- **مكتبة مرجعية شاملة (253 صنف):**
  - أنظمة الإنذار التقليدية والمعنونة (لوحات تحكم، كواشف، نقاط استدعاء، أجهزة تنبيه، وحدات، كابلات، مواسير تمديدات)
  - أنظمة الإطفاء (طفايات، أنابيب بجميع المقاسات، أكواع وتيه ونقاصات ووصلات، علاقات ومثبتات، محابس وصمامات، رشاشات، خراطيم وصنابير، مضخات، أنظمة الغاز)
- **حساب ذكي:** توريد + تركيب + عمالة + مواد + خدمات هندسية + نفقات عامة + طوارئ + ربح + ضريبة + خصم
- **تحليل احترافي:** هامش الربح، سعر النقطة، السعر لكل م²، تحذيرات ذكية عند ضعف التغطية
- **تقدير الكابلات تلقائياً** حسب عدد الأجهزة
- **عرض سعر احترافي** قابل للطباعة / حفظ PDF
- **حفظ واسترجاع المشاريع** على جهازك

## التشغيل كتطبيق سطح مكتب

### المتطلبات
- [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث) + npm

### الخطوات

```
# تنزيل المشروع وفك الضغط
cd fire-pricing

# تثبيت المتطلبات (مرة واحدة)
npm install

# تشغيل التطبيق
npm start
```

سيتم فتح نافذة تطبيق سطح مكتب كاملة. تطبع عرض السعر مباشرة من قائمة "ملف" أو بالضغط على `Ctrl+P`.

### ملاحظة عن الملفات المحفوظة
المشاريع المحفوظة تُخزن داخل بيانات التطبيق المحلية (localStorage) على جهازك ولا تُرسل لأي مكان.

## التشغيل عبر المتصفح (بديل)

بدون Electron، يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم بسيط:

```
python3 -m http.server 8000
```

ثم فتح `http://localhost:8000`.

## بنية المشروع

```
├── index.html          الواجهة الرئيسية
├── main.js             نقطة دخول تطبيق سطح المكتب (Electron)
├── package.json        إعدادات Electron
├── css/style.css       التنسيقات
├── js/
│   ├── data.js         قاعدة البيانات المرجعية (الأجهزة والأسعار)
│   └── app.js          منطق البرنامج والحسابات
└── icons/              أيقونات التطبيق
```

## تطوير المشروع

- **قاعدة البيانات:** أضف/عدّل الأصناف والأسعار في `js/data.js` داخل المجموعات المناسبة.
- **الحسابات:** موضوعة في `js/app.js` داخل دوال `calcBase()` و `calcFull()`.
- **التطوير معاً:** يمكن إضافة ميزات مثل أرقام عروض تسلسلية، لوجو الشركة، تصدير Excel، تقارير فروق الأسعار.
