# نظام التسعير الذكي لأنظمة الإطفاء والإنذار من الحريق

برنامج احترافي لتسعير مشاريع توريد وتركيب أنظمة الحماية من الحرائق، بواجهة عربية كاملة، **مع قاعدة بيانات SQLite** ومكتبة مرجعية قوية للأجهزة والمواد.

## المزايا

- **قاعدة بيانات SQLite** (ملف واحد `fire-pricing.db` في مجلد بيانات التطبيق) — بدلاً من localStorage
- **مكتبة مرجعية (310 أصناف):** 253 جهازاً (إنذار + إطفاء) و 57 مادة (كابلات، مواسير، علب، حوامل، دهانات...)
- **إدارة الكتالوج من داخل التطبيق:** إضافة/تعديل/إيقاف أصناف، ماركات، أكواد، موردين، وحدات قياس
- **سجل أسعار كامل:** كل تغيير سعر يُسجل بتاريخه وسببه — وتحديث أسعار شامل بنسبة واحدة (زيادة/خصم) لفئة كاملة
- **سجل عملاء:** اسم، جوال، بريد، سجل تجاري، مدينة — مع اختيار العميل في المشروع
- **ترقيم عروض تلقائي** (Q-2026-0001) وحالات مشروع (مسودة/مرسل/معتمد/ملغي)
- **حساب ذكي:** توريد + تركيب + عمالة + مواد + خدمات + نفقات عامة + طوارئ + ربح + ضريبة + خصم
- **تحليل احترافي:** هامش الربح، سعر النقطة، السعر لكل م²، تحذيرات ذكية عند ضعف التغطية
- **تقدير الكابلات تلقائياً** حسب عدد الأجهزة
- **عرض سعر احترافي بوضعين:** 📄 "عرض العميل" (أسعار البيع فقط دون تكاليف أو أرباح — يُطبع ويُرسل للعميل) و 📊 "التقرير الداخلي" (التكاليف والهوامش والأرباح)
- **كتابة مباشرة في كل الحقول:** الأرقام والأسماء تُكتب يدوياً بحرية (دون فقدان التركيز)
- **العميل بسجل تلقائي:** اكتب اسم العميل مباشرة في المشروع — يُضاف تلقائياً لسجل العملاء
- **إعدادات الشركة:** اسم شركتك ولوجوها وجوالها وبريدها وسجلها التجاري وشروط العرض المخصصة — تظهر في رأس عرض السعر
- **نسخة احتياطية JSON** لقاعدة البيانات كاملة
- **استيراد المشاريع المحفوظة** من النسخة السابقة (localStorage) بزر واحد

## التشغيل كتطبيق سطح مكتب

### المتطلبات
- [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث) + npm

### الخطوات

```bash
cd fire-pricing
npm install
npm start
```

> **ملاحظة:** مكتبة `better-sqlite3` توفر نسخاً جاهزة (prebuilt) لمعظم الأجهزة. إن ظهرت رسالة تتعلق بإعادة البناء عند التشغيل، نفّذ مرة واحدة:
> ```bash
> npm run rebuild
> ```

### إنتاج ملف تثبيت (Windows / macOS / Linux)
```bash
npm run dist
```
ينتج ملفات تثبيت جاهزة داخل مجلد `dist/`.

## قاعدة البيانات (SQLite)

- **الموقع:** `userData/fire-pricing.db` — في Windows: `%APPDATA%/fire-pricing/fire-pricing.db`
- **النسخ الاحتياطي:** زر "نسخة احتياطية (JSON)" في القائمة الجانبية — يحفظ كل الجداول في ملف JSON واحد
- **الترحيل:** المخطط مُدار عبر `PRAGMA user_version` — الترقيات القادمة تُضاف دون فقدان بياناتك

### الجداول
| الجدول | الوصف |
|---|---|
| `categories` | فئات الأجهزة والمواد (مع نظام: إنذار/إطفاء) |
| `items` | الأصناف: كود، اسم، ماركة، موديل، وحدة، سعر توريد/تركيب، مورد |
| `price_history` | سجل تغيرات الأسعار (السعر، المصدر، التاريخ) |
| `clients` | العملاء |
| `projects` | المشاريع: رقم عرض تسلسلي، حالة، هوامش، إجمالي |
| `project_items` | بنود كل مشروع (أجهزة/مواد/عمالة/خدمات) |

## 🔐 نظام الترخيص

البرنامج محمي بنظام ترخيص: لا يعمل بدون مفتاح ترخيص صادر من المالك، وكل مفتاح **مربوط بجهاز واحد** (بصمة عتاد) فلا يمكن نسخه لجهاز آخر. من دون ترخيص يعمل البرنامج **نسخة تجريبية 30 يوماً** ثم يُقفل.

### للمالك — إصدار التراخيص (مرة واحدة)

**1) توليد مفاتيحك الخاصة (مرة واحدة فقط — احتفظ بالمفتاح الخاص ولا ترفعه):**
```
npm run license:keys
```
ينتج:
- `license-keys/private-key.pem` ← **سري جداً — احتفظ به ولا ترفعه للمستودع أبداً**
- `js/license-public-key.js` ← يُدمج في التطبيق ويُرفع للمستودع

> ⚠️ إن أعدت توليد المفاتيح، **تُبطل كل التراخيص** الصادرة سابقاً — فلا تفعلها إلا للضرورة.

**2) إصدار ترخيص لعميل:**
```
node tools/generate-license.js --name "اسم العميل" --machine XXXX-XXXX [--days 365]
```
- `--machine`: رمز الجهاز الذي يظهر في نافذة تفعيل الترخيص عند العميل
- `--this-machine`: بديل يلتقط بصمة جهازك الحالي (لترخيص جهازك أنت)
- `--days`: مدة الصلاحية بالأيام — بدونها يكون الترخيص **دائماً**
- الناتج: مفتاح ترخيص يُرسل للعميل فيُلصقه في نافذة التفعيل

### للعميل — التفعيل
1. يفتح البرنامج → إن لم يكن مرخصاً تظهر نافذة التفعيل
2. ينسخ "رمز الجهاز" ويرسله للمالك
3. يلصق مفتاح الترخيص → "تفعيل الترخيص" → يعمل البرنامج فوراً

### ملاحظات أمنية
- المفتاح الخاص هو **سلطتك الوحيدة** لإصدار التراخيص — فقده يعني فقدان القدرة على إصدار تراخيص جديدة (التطبيق نفسه يستمر بالعمل للتراخيص الصادرة)
- التحقق يتم محلياً بتوقيع RSA-2048 — لا يحتاج إنترنت
- شارة حالة الترخيص تظهر دائماً أعلى التطبيق (مرخص / تجريبي / غير مرخص)

## 📥 استيراد الأسعار من Excel / CSV

حدّث أسعار المكتبة دفعة واحدة من قائمة أسعار موردك:
1. تبويب "الكتالوج والمكتبة" ← زر **"📥 استيراد أسعار من Excel"**
2. اختر ملف الأسعار (Excel أو CSV — يدعم العربية والفاصلة المنقوطة)
3. حدد الأعمدة: اسم الصنف، السعر، الوحدة (اختياري)، الكود (اختياري)
4. **مطابقة ذكية**: تتجاهل الأقواس والترجمة الإنجليزية (مثلاً "كاشف دخان تقليدي" تطابق "كاشف دخان تقليدي (Smoke Detector)")
5. اختر: تحديث سعر التوريد أو التركيب، وإضافة الأصناف غير الموجودة
6. كل تغيير يُسجل في سجل الأسعار بمصدر "استيراد Excel"

> في وضع المتصفح يدعم CSV فقط — ملفات Excel تحتاج النسخة المثبتة.
