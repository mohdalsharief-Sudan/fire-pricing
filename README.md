# \# نظام تسعير أنظمة مكافحة وإنذار الحريق (Fire Pricing) 🔥

# 

# تطبيق سطح مكتب احترافي مخصص لمهندسي ومقاولي أنظمة الحماية من الحريق. يتيح البرنامج إدارة المشاريع، إنشاء عروض الأسعار، حساب التكاليف وهوامش الربح، والتحكم الشامل بمكتبة الأجهزة والمواد.

# 

# \## 🚀 التحديثات الأخيرة (الإصدار الحالي)

# شهد المشروع إعادة هيكلة برمجية شاملة (Refactoring) للانتقال إلى بنية احترافية قابلة للتوسع (Modular Architecture):

# \* \*\*تفكيك الواجهة:\*\* تم تقسيم الملف العملاق `app.js` إلى ملفات واجهة مستقلة (`company.js`, `clients.js`, `projects.js`) لسهولة الصيانة.

# \* \*\*استقرار الواجهة (UI Stability):\*\* تأمين ربط أزرار الواجهة لمنع الانهيارات، وحل مشكلة التداخل في معرفات (IDs) بيانات العميل والشركة.

# \* \*\*إدارة بيئة Electron:\*\* تحديث `package.json` ليشمل أوامر ذكية تعالج مشاكل التثبيت وتضمن بناء المكتبات الأصلية (مثل `better-sqlite3`) بشكل متوافق تماماً.

# \* \*\*سلامة البيانات:\*\* إصلاح تسلسل أرقام عروض الأسعار التلقائي (Quote Numbering) بعد الحذف، وتحسين آلية دمج إعدادات الشركة بـ JSON.

# 

# \## 🛠️ الميزات الأساسية

# \* \*\*تسعير تفصيلي:\*\* توريد وتركيب وعمالة ومواد واستهلاكات.

# \* \*\*مكتبة متكاملة (Catalog):\*\* تحتوي افتراضياً على أكثر من 300 صنف (مضخات، كواشف، لوحات...) مع إمكانية التعديل الشامل للأسعار.

# \* \*\*إدارة المشاريع:\*\* حفظ، استرجاع، بحث، وحذف المشاريع بضغطة زر.

# \* \*\*إدارة العملاء:\*\* قاعدة بيانات مستقلة للعملاء وربطهم بالمشاريع.

# \* \*\*تصدير واستيراد:\*\* تصدير جداول الكميات إلى Excel (BOQ)، وأخذ نسخ احتياطية (JSON).

# \* \*\*إعدادات الشركة:\*\* تخصيص الشعار، بيانات الاتصال، وشروط العرض لتظهر تلقائياً في عروض الأسعار.

# \* \*\*حسابات ذكية للربحية:\*\* هوامش طوارئ، أرباح، وتكاليف تشغيلية.

# 

# \## 📁 الهيكلية الجديدة للمشروع (Modular Architecture)

# ```text

# fire-pricing/

# ├── main.js                 # نقطة دخول Electron وإدارة النوافذ

# ├── index.html              # الواجهة الرئيسية (UI)

# ├── js/

# │   ├── api.js              # طبقة الاتصال بقاعدة البيانات (IPC / SQLite)

# │   ├── calc.js             # محرك الحسابات (منفصل ونقي)

# │   ├── utils.js            # الأدوات والدوال المساعدة العامة

# │   ├── app.js              # ملف التهيئة الرئيسي (Bootstrapper)

# │   └── ui/                 # مجلد وحدات الواجهة المستقلة

# │       ├── company.js      # نافذة إعدادات الشركة

# │       ├── clients.js      # إدارة العملاء

# │       └── projects.js     # إدارة المشاريع (حفظ واسترجاع)

# ├── src/

# │   ├── db/database.js      # مخطط SQLite والترحيلات

# │   └── ipc.js              # معالجات الاتصال بين الواجهة والنظام

# └── css/                    # تنسيقات الواجهة (الوضع المظلم/الفاتح)



⚙️ متطلبات التشغيل

يوصى باستخدام Node.js LTS (الإصدار 22 أو أحدث).

نظام التشغيل: Windows / macOS / Linux.

💻 التثبيت والتشغيل السريع

تم تصميم سكربتات ذكية لتسهيل تثبيت Electron وتهيئة قاعدة البيانات تلقائياً:



تثبيت الحزم:

Bash



npm install

تشغيل البرنامج (يقوم بتهيئة Electron تلقائياً):

Bash



npm start

أوامر مفيدة للمطورين:

لتشغيل اختبارات الأداء وقاعدة البيانات:

Bash



npm test

في حال ظهور مشاكل مع better-sqlite3، استخدم أمر إعادة البناء:

Bash



npm run rebuild
